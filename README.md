# Exercícios de Python 3

Repositório de exercícios desenvolvidos durante minha formação em programação Python, com base no curso Python 3 do Curso em Vídeo, ministrado por Gustavo Guanabara.

## Objetivo

Registrar minha evolução em programação, consolidando fundamentos da linguagem Python, lógica computacional e resolução de problemas por meio de exercícios práticos.

## Conteúdos estudados

### Mundo 1 — Fundamentos

- Variáveis e tipos de dados.
- Operadores aritméticos.
- Manipulação de strings.
- Entrada e saída de dados.
- Utilização de módulos.
- Estruturas condicionais.

### Mundo 2 — Estruturas de controle

- Condições aninhadas.
- Estruturas de repetição `for` e `while`.
- Validação de entradas.
- Desenvolvimento de algoritmos.

### Mundo 3 — Estruturas de dados e funções

- Tuplas, listas e dicionários.
- Manipulação de estruturas de dados aninhadas.
- Funções e parâmetros.
- Organização e reutilização de código.

## Organização

Os exercícios estão disponíveis no diretório `exerciciosgu/`, identificados por numeração conforme a sequência do curso.

Alguns exercícios possuem versões alternativas ou refatoradas, desenvolvidas durante o processo de aprendizagem.

Os códigos representam diferentes etapas da minha formação e foram preservados para registrar a evolução do meu aprendizado.

## Continuidade

Os conhecimentos desenvolvidos neste repositório servem como base para meu projeto de desenvolvimento de um CRM de visitas comerciais utilizando Python e SQL.
